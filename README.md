# Tarea 2 — Estructuras iterativas en Python
Curso: SOFT-01 Principios de Programación 
Autor: Edgar Luis Alfaro Quirós
## Ejercicios
1. `ejercicio1_temperatura.py`: control de temperatura de una cámara experimental (while).
2. `ejercicio2_consumo_agua.py`: registro semanal de consumo de agua (for).
3. `ejercicio3_estacionamiento.py`: administración de un estacionamiento privado (menú con while True).
4. `ejercicio4_expedicion.py`: control de abastecimiento de una expedición (for, while y break).
## Cómo ejecutar
Requiere Python 3. Desde la terminal, en la carpeta del proyecto:
    python ejercicio1_temperatura.py
Cambie el nombre del archivo para correr cada ejercicio.
